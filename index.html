Dictionary

Concepts behind it

TrieA tree where each step is a letter. Looking up a word costs one step per letter, no matter how big the dictionary is.
String matchingComparing the typed word with stored words, letter by letter.
Edit distanceThe fewest insertions, deletions and replacements needed to turn one word into another (Levenshtein distance), solved with a table of sub-answers.
VectorThe list of dictionary words kept alongside the trie so every word can be scored for suggestions.
File handlingThe C++ program reads and appends to dictionary.txt; here the textarea above plays that role, and the browser remembers your list.
SortingSuggestions are ordered by distance, then alphabetically, so the closest word comes first.
